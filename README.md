## 🔐 Projects

### 1. Wazuh SIEM Monitoring Lab

A hands-on security monitoring lab focused on SIEM-based event analysis, endpoint security monitoring, and File Integrity Monitoring.

**Key activities:**
- Configured Wazuh for security event monitoring and log analysis.
- Used Sysmon and Windows security telemetry for endpoint visibility.
- Investigated brute-force and discovery activity.
- Implemented File Integrity Monitoring (FIM) for sensitive files in Kali Linux.
- Used PowerShell to execute commands and generate security telemetry in the lab.

**Technologies:** Wazuh, Sysmon, Kali Linux, PowerShell, File Integrity Monitoring.

### 2. Microsoft Sentinel SOC Lab

A cloud-based SOC monitoring lab using Microsoft Sentinel to analyze Windows security activity and develop scheduled detections using Kusto Query Language (KQL).

**Key activities:**
- Configured Microsoft Sentinel and its supporting Azure resources for security monitoring.
- Connected the Windows endpoint using Azure Arc and configured the Azure Monitor Agent.
- Set up a Data Collection Rule (DCR) to collect relevant Windows security events.
- Created four individual KQL-based scheduled analytics rules for remote brute-force attempts, privilege escalation attempts, defense-evasion commands, and discovery command execution.
- Analyzed Windows security events, including Event IDs 4625 and 4688 where relevant.
- Explored alert investigation workflows and MITRE ATT&CK mapping.

**Technologies:** Microsoft Sentinel, Microsoft Azure, Azure Arc, Azure Monitor Agent, Data Collection Rules, KQL, Windows Security Events, MITRE ATT&CK.
